來 Rice 前原本目標只打算認真找 summer intern 其他部分放少一點重心，但來了之後因為各種因緣際會也是認識了一群很棒的朋友，享受跟朋友相處的過程也就變得重要起來，時間分配真的是留學期間很難的課題，在找到 summer intern 以前時間永遠都不夠用。

這篇主要記錄找工吧，有時候真的會懷疑自己在台灣待得好好的，工作輕鬆找為什麼要來這裡為了五斗米折腰，太多細節要注意了，最麻煩的是拿不到面試根本就沒有辦法知道哪個環節出問題，有時候其實也就是運氣問題也不是什麼環節出問題，只能想辦法把各種細節做好，然後準備好面對隨時會出現的面試。

首先最重要的就是履歷，履歷上硬實力的區別就不在這裡討論了，但在自己有限的 work experience 跟 project 身上，還是要想辦法把自己優勢凸顯出來，太多細節要注意了，一頁式履歷，包含 Education / Work Experience / Project / Publication / Technical Skills / 等重要的 Section，基本上每一條 bullet points 都要很認真的措辭過，動詞開頭，重點 keyword 要 highlight，如果每一點都能有可以「量化」的 impact 會更有說服力，還有排版等問題要注意，然後由於美國競爭實在是太激烈，很多公司會直接拿 ATS 掃履歷而不會人工看，所以我還捨棄掉 latex 改用 word 排履歷，因為有聽過一些 rumors 是說 latex 對於 ATS 比較不友善，可能會掃不到一些重要資訊。
